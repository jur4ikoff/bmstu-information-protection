# Отчёт по лабораторной работе №7

[report.pdf](report.pdf) — собранный отчёт, [report.typ](report.typ) — исходник Typst.
Описаны три задания из DOCX, включены диаграммы частот, результаты Казиски,
таблицы индекса совпадений и χ², восстановление ключа и текста, оценка точности,
выводы и приложения с алгоритмами и полным расшифрованным сообщением.
Контрольных вопросов в условии нет; соответствующий раздел не добавлен.

Команды выполняются из корня репозитория:

```sh
# При необходимости воспроизвести эксперименты:
python3 lab_07/main.py experiment
python3 lab_07/main.py experiment --language en --output lab_07/results/experiment_en
python3 lab_07/main.py analyze

# Сверить сохранённые результаты с исходниками и обновить данные отчёта:
python3 lab_07/docs/prepare_report.py

# Собрать PDF (нужен установленный Typst):
typst compile --no-pdf-tags --root lab_07 lab_07/docs/report.typ
```

`prepare_report.py` проверяет сохранённые статистики, шифрование четырёх
криптограмм, точность восстановления и неизменность нешифруемых символов.
Он создаёт `report-data.json` с данными таблиц и фрагментами актуального кода,
а также `results.txt` с краткими результатами. Диаграммы подключаются прямо
из `../results/experiment/` и `../results/experiment_en/`.

Основные численные таблицы берутся из JSON. Если параметры эксперимента
меняются, нужно также проверить поясняющий текст отчёта: он описывает
конкретный сохранённый запуск с ключами КЛЮЧ, ИНФОРМАЦИОННАЯЗАЩИТА,
KEY, INFORMATIONSECURITY и криптограммой из условия.
