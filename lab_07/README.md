# Лабораторная работа №7 — шифр Виженера и криптоанализ

Python 3.10+, без сторонних пакетов. Таблицы вариантов в условии нет.
Команды ниже запускаются из корня репозитория.

Отчёт: [docs/report.pdf](docs/report.pdf), исходник: [docs/report.typ](docs/report.typ).
Подготовка и сборка описаны в [docs/README.md](docs/README.md).

## Шифрование и расшифрование

```sh
python3 lab_07/main.py encrypt --language ru --key КЛЮЧ --input lab_07/data/sample_ru.txt --output lab_07/results/encrypted.txt
python3 lab_07/main.py decrypt --language ru --key КЛЮЧ --input lab_07/results/encrypted.txt --output lab_07/results/decrypted.txt
```

Алфавиты: `ru` — 32 буквы без Ё, `ru33` — 33 буквы с Ё после Е,
`en` — 26 английских букв. Регистр сохраняется. Символы вне выбранного
алфавита, включая пробелы, цифры и пунктуацию, сохраняют свои позиции
и не продвигают ключ. При `ru` буквы Ё/ё сохраняются без шифрования.
Файлы читаются и записываются в UTF-8 с сохранением переводов строк.
Ключ должен целиком состоять из букв выбранного алфавита.

## Эксперимент на 100 000 символов

```sh
python3 lab_07/main.py experiment
python3 lab_07/main.py experiment --language en --output lab_07/results/experiment_en
python3 lab_07/main.py experiment --input large_text.txt --language ru --short-key КЛЮЧ --long-key ИНФОРМАЦИОННАЯЗАЩИТА
```

По умолчанию используется русский текст, короткий ключ `КЛЮЧ` (4 буквы)
и длинный `ИНФОРМАЦИОННАЯЗАЩИТА` (20 букв). Подготовленный корпус состоит
из перемешанных авторских абзацев `data/sample_ru.txt` либо `sample_en.txt`,
повторяемых до нужного размера. Генератор воспроизводим. Эти повторы могут
облегчать анализ Казиски; для исследования независимого текста передайте
свой файл через `--input` (минимум 100 000 символов).

В `lab_07/results/experiment/` создаются:

- `original.txt`, `short.txt`, `long.txt` — исходный текст и криптограммы;
- `statistics.json`, `frequencies.csv` — количества и частоты букв, частоты
  всех символов, индекс совпадений и эмпирическая энтропия;
- `letters_original.svg`, `letters_short.svg`, `letters_long.svg` — диаграммы букв;
- `letters_comparison.svg` — сравнительная диаграмма частот;
- `letters_distribution.svg`, `symbols_distribution.svg` — графики распределений;
- `attack_short/`, `attack_long/` — результаты автоматического восстановления;
- `summary.txt` — численные результаты и выводы.

SVG можно открыть в браузере. Длина ключа сама по себе не гарантирует
равномерность частот: имеет значение и распределение сдвигов в ключе.

## Криптограмма из условия

```sh
python3 lab_07/main.py analyze
```

Криптограмма извлечена из DOCX в `data/teacher_ciphertext.txt`, переносы
строк сохранены. Для русского алфавита без Ё автоматически найден ключ
`СЕКРЕТЫ`, длина **7**. Результаты находятся в `results/analyze/`:
расшифрованный текст `decrypted.txt`, подробности `analysis.json`, таблица
гипотез длины `key_lengths.csv`.

Произвольная криптограмма и ручная проверка гипотезы:

```sh
python3 lab_07/main.py analyze --input cipher.txt --language en --max-key-length 50 --output lab_07/results/custom
python3 lab_07/main.py analyze --input cipher.txt --language en --key-length 7
```

Алгоритм Казиски ищет повторения n-грамм длиной 3–5, считает расстояния
между соседними повторениями по позициям букв, их делители и общий НОД.
Соседние расстояния позволяют избежать квадратичного числа пар; их НОД
равен НОД всех попарных расстояний. Случайные повторы могут сделать общий
НОД равным 1, поэтому дополнительно используются голоса делителей и IC.

Для каждой длины от 1 до `--max-key-length` рассчитывается средний индекс
совпадений групп. Гипотезы с повышенным IC проверяются частотным анализом:
для каждой позиции ключа выбирается сдвиг с минимальным χ² относительно
эталонных частот языка. Среди подходящих периодов выбирается максимальное
правдоподобие букв расшифровки со штрафом за длину ключа. Это помогает
различать основной период и кратные ему длины. В JSON сохраняются все
гипотезы, оценки χ² всех сдвигов, примеры повторов и обоснование выбора.

Повторное шифрование проверяет точную обратимость, но возможно для любого
ключа и само по себе не доказывает правильность восстановления.
Для неизвестного сообщения точность без эталона определить нельзя.
В эксперименте исходный текст и ключ известны, поэтому точность считается
явно. При наличии эталона его можно передать и команде анализа:

```sh
python3 lab_07/main.py analyze --input cipher.txt --language en --known-plaintext original.txt --known-key SECRET
```

Короткие тексты, необычная лексика и ключи с периодом за пределами диапазона
поиска могут приводить к ошибкам восстановления. Шифр Виженера используется
здесь для учебного исследования.

## Проверки

```sh
python3 -m unittest discover -s lab_07/tests -v
```

Проверяются известный вектор `ATTACKATDAWN` / `LEMON`, сохранение регистра
и нешифруемых символов, работа Ё, обработка неверных параметров, Казиски,
восстановление ключей на обоих языках, длинный ключ, кратные периоды
и криптограмма из задания.
