# Лабораторная работа №6 — вариант 15

Хеш-функции, лавинный эффект SHA-256, свойства CRC, поиск коллизий,
HMAC и хранение паролей с PBKDF2. Используется только стандартная
библиотека Python (hashlib, hmac, os, secrets, zlib).

Параметры: сообщение `user=student15&role=user`, ключ 24 байта,
HMAC-SHA-384 с усечением до 192 бит, коллизии SHA-256 с усечением до 40 бит.
Реализовано дополнительное задание: ручной HMAC.

Запуск из корня репозитория, без ввода номера варианта:

```sh
python3 lab_06/template.py
```

Программа выполняет пять поисков коллизий со словарём хешей; для 40 бит
каждый поиск требует порядка миллиона попыток и заметного объёма памяти.
Число попыток, соли и время проверки пароля меняются между запусками.

Сохранённый запуск: [docs/results.txt](docs/results.txt).
Отчёт: [docs/report.pdf](docs/report.pdf), исходник: [docs/report.typ](docs/report.typ).

Сборка отчёта из корня репозитория:

```sh
typst compile --no-pdf-tags --root lab_06 lab_06/docs/report.typ
```

В отчёте приведены результаты сохранённого запуска; при новом эксперименте
нужно обновить численные результаты в исходнике отчёта.
