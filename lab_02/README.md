# Усовершенствованная Enigma

Программа — учебный электронный аналог Enigma для байтового алфавита `0..255`.
Она обрабатывает ZIP/TAR-архивы блоками по 64 КиБ, поэтому весь архив никогда
не загружается в оперативную память.

> Это лабораторная криптосистема, а не замена AES-GCM: Enigma намеренно
> уязвима для криптоанализа.

## Шифрование всего архива

```sh
go run ./cmd/enigma -e -i backup.zip -o backup.egar \
  --rotors IV,II,I,III --reflector B --positions 7,12,34,56 \
  --plugboard 65:66,0x01:0xff

go run ./cmd/enigma -d -i backup.egar -o restored.zip \
  --rotors IV,II,I,III --reflector B --positions 7,12,34,56 \
  --plugboard 65:66,0x01:0xff
```

Также доступны команды `encrypt` и `decrypt`. Контейнер `ENIGAR1` содержит
версию, тип и размер исходного архива, а в конце — `HMAC-SHA-256` от заголовка
и шифротекста. При неверной установке роторов или повреждении данных результат
не публикуется: временный файл удаляется, а существующий файл назначения не
заменяется. Пустые файлы и архивы меньше периода роторов обрабатываются тем же
потоковым циклом. Вложенная структура в этом режиме сохраняется побайтно.

Поддерживаются входные `.zip` и `.tar`.

## Выборочные записи в архиве

`entries` создаёт обычный ZIP/TAR и преобразует только указанные записи, не
распаковывая архив в каталог на диске:

```sh
go run ./cmd/enigma entries -i source.zip -o selected.zip \
  --files docs/readme.txt,images/logo.bin --positions 7,12,34,56

go run ./cmd/enigma entries -d -i selected.zip -o restored.zip \
  --positions 7,12,34,56
```

В архив добавляется служебная запись `.enigma-auth.json`: список выбранных
файлов и HMAC логического содержимого. Перед расшифровкой HMAC проверяется
отдельным потоковым проходом, поэтому неверный ключ не повреждает метаданные
или файл назначения.

## Конфигурационный файл

Параметры можно хранить в JSON и передать через `--config machine.json`:

```json
{
  "rotors": ["IV", "II", "I", "III"],
  "reflector": "B",
  "positions": "7,12,34,56",
  "plugboard": ["65:66", "0x01:0xff"]
}
```

В машине всегда работают четыре ротора `I`, `II`, `III`, `IV`; флаг `--rotors`
задает их порядок. Доступны отражатели `A` и `B`. Пары коммутационной панели
не могут использовать один символ дважды.

## Демонстрация атаки известного текста

Команда ниже перебирает одну неизвестную пару панели при известных
роторах/позициях. По умолчанию она использует начало ZIP `PK\003\004`:

```sh
go run ./cmd/enigma attack -i backup.egar \
  --rotors IV,II,I,III --reflector B --positions 7,12,34,56
```

Это ограниченная учебная атака: предполагается ровно одна неизвестная пара.
Для TAR можно использовать `--known-hex 7573746172 --offset 257` (`ustar`).

Для полностью воспроизводимой проверки выполните из `lab_02`:

```sh
./scripts/demo_attack.sh
```

Скрипт создаёт временный ZIP, шифрует его с секретной парой `65:66` и
показывает, что она входит в множество кандидатов, отобранных атакой.
