# Лабораторная 1: Enigma

Симулятор Enigma написан на Go и шифрует файл как поток битов. Каждый байт
обрабатывается побитово, поэтому формат файла и его размер сохраняются:
можно передавать текст, изображения и другие бинарные данные. Повторное
применение с одинаковыми параметрами расшифровывает результат.

```sh
go run ./cmd/enigma encrypt \\
  --input plaintext.txt \\
  --output ciphertext.txt \\
  --positions MCK \\
  --plugboard "AV BS CG"
```

Параметры:

- `--input`, `-i`: входной файл;
- `--output`, `-o`: выходной файл;
- `--positions`, `-p`: начальные позиции роторов I-II-III, по умолчанию `AAA`;
- `--plugboard`: пары штекерной панели, разделённые пробелами.
