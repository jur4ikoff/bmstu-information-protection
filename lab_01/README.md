# Лабораторная 1: Enigma

Симулятор шифрует любой поток байтов. Это обобщение механизма Enigma на
алфавит из 256 значений (`0..255`): три ротора, отражатель и двойное вращение
среднего ротора сохранены, но каждый ротор имеет 256 контактов. Штекерная
панель отключена.

```sh
go run ./cmd/enigma encrypt \\
  --input plaintext.txt \\
  --output ciphertext.txt \\
  --positions 12,34,56
```

Расшифрование использует те же начальные настройки:

```sh
go run ./cmd/enigma decrypt \\
  --input ciphertext.txt \\
  --output decrypted.txt \\
  --positions 12,34,56
```

Параметры:

- `--input`, `-i`: входной файл;
- `--output`, `-o`: выходной файл, по умолчанию `output.txt`;
- `--positions`, `-p`: три числа от `0` до `255` через запятую, по умолчанию `0,0,0`.
